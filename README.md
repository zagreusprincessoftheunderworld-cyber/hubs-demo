# Конфигуратор сети хабов (демо)

Пример на условных данных. Числа показывают работу метода, а не итог по реальной компании.

Что внутри:
- `index.html` — страница с двумя кнопками («Рассчитать сеть» и «Стресс-тест»), работает в браузере без установки.
- `Model_hubs.xlsx` — расчёт в Excel с формулами. Первый лист объясняет, как им пользоваться.
- `hubs_model.py` — тот же расчёт на Python. Запуск: `python hubs_model.py`.
- `app.py` — версия на Streamlit. Запуск: `pip install streamlit`, затем `streamlit run app.py`.

Допущения: спрос 110 тыс. т/год в 7 регионах, 5 хабов-кандидатов, 4 сценария (базовый, тарифы +30%, граница закрыта, оба сразу). Стоимость хранения, ставки и сроки условные.
